# QUALIA ACADEMY

株式会社QUALIA 会員向けの「考え方・あり方」＋「コンプライアンス」学習Webアプリ（テスト公開版）。

- 役員の言葉カード集（テーマ別・出典動画リンク付き）／毎日の一言
- コンプライアンステスト（初級／リーダー・プレゼンター編、合格80%、解説・補足つき、再受験可）
- 合格すると受講者名・会員ナンバー入りの修了証PDFを発行
- 受講履歴（端末内 localStorage に保存）

## 技術
Vite + React + TypeScript + Tailwind CSS。サーバー不要の静的SPA（GitHub Pages 配信、HashRouter）。

## 開発
```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run deploy   # GitHub Pages へ公開（gh-pages ブランチ）
```

> 学習・テスト内容は社内教育用の草案です。法令の最終的な解釈・運用は会社の公式案内に従ってください。
